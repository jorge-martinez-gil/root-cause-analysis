# Code of Conduct

## Our Pledge

We as contributors pledge to make participation in this project a harassment-free experience for everyone.

## Standards

Examples of behavior that contributes to a positive environment include:
- Using welcoming and inclusive language.
- Being respectful of differing viewpoints.
- Giving and gracefully accepting constructive feedback.

## Enforcement

Please report unacceptable behavior by opening a confidential issue addressed to project maintainers.
