# Usage Guide

## Installation

```bash
python -m pip install -e .
```

## Quickstart

```bash
python examples/minimal_quickstart.py
```

## Ontology Query

```bash
python query.py
# or
rca-query --ontology data/ontology/onto_pw.owl --min-water-level 100
```

## Classification

```bash
python swrl-rules.py
# or
rca-classify
```
