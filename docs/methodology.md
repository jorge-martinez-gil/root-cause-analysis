# Methodology Overview

This repository implements a knowledge graph-driven approach for root cause analysis in power transformers.

## Components

1. **Ontology querying**: SPARQL query over the transformer ontology to identify high-risk assets (e.g., high water content).
2. **Rule-based classification**: Threshold rules derived from the publication examples to classify records as failure/non-failure candidates.

## Scope

The codebase is intentionally lightweight for reproducibility and educational use. It does not claim to replace production-grade asset management systems.
