# Methodology

This repository implements an explainable, knowledge-graph-driven pipeline for root cause analysis (RCA) of
power transformers. The pipeline has four stages.

## 1. Knowledge graph construction

Measurements (one row per asset) are materialised as RDF individuals against a documented OWL **TBox**
(`data/ontology/onto_pw.ttl`). The schema is generated programmatically from `src/root_cause_analysis/ontology.py`
so that it is always internally consistent: every property used by the reasoner is declared, and every class
carries an `rdfs:label` and `rdfs:comment`. The ontology separates assets, components, sensors, measurements,
symptoms, faults, causes, effects and maintenance actions.

## 2. SPARQL screening

A SPARQL query selects assets whose measured parameters cross a configurable threshold (for example, a low
composite health index). This mirrors the screening step of the original case study and is implemented in
`querying.py`.

## 3. Rule-based root-cause reasoning

The dominant fault is classified with the **IEC 60599** basic gas-ratio method (also reproduced in
**IEEE C57.104-2019**) using the ratios `R1 = C2H2/C2H4`, `R2 = CH4/H2` and `R5 = C2H4/C2H6`. The method is only
applied when gassing is *significant* (a key gas exceeds its IEC 60599 90 %-typical value), which avoids
diagnosing faults from background noise. Advisory oil-quality and health rules add supporting symptoms. The full
rule specification is in `data/rules/swrl_rules.md`.

## 4. Explanation and provenance

Each diagnosis records the rules that fired and the exact evidence (parameter, value, operator, threshold), and
is materialised back into the knowledge graph using the **W3C PROV-O** vocabulary: a diagnosis is a `prov:Entity`
generated by a rule-application `prov:Activity` that `prov:used` the supporting measurements. The result is a
SPARQL-queryable, auditable diagnosis.

## Scope

The codebase is intentionally lightweight and reproducible. It is a reference reasoning pipeline and case study,
not a replacement for production asset-management systems. A full benchmark suite is on the roadmap.
